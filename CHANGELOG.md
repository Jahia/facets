# facets Changelog

## 0.1.0

### New Features

* Changed the minimum Jahia version to 8.2.2.0. A site on an earlier Jahia version keeps facets 8.1.0.

* Fixed the tag cloud, the facet group headings and the facet summary in edit mode so that a value with quotes or HTML characters displays as plain text. A label that relied on HTML markup now shows that markup as text.

### Bug Fixes

* Added maven.jahia.com to the Maven repositories facets uses to download its dependencies.
